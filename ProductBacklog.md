### Mandat

Faire un préprocesseur ou un post-processeur pour pouvoir ajouter une fonction de MarkDown. La fonction de MarkDown ajoutée est une checklist.

* Regarder comment fonctionne le markdown afin de déterminer le fonctionnement du code.
* Faire un prototype fonctionnel du code.
* Tester le fonctionnement du code prototype.
* Faire la version finale du code.
* Tester le fonctionnement du code final.
* Ajouter de la documentation au code.
